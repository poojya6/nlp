## 🧪 Experiment Documentation

Every experiment folder inside `Experiment/` contains a `README.md` with the following structured sections:

| Section | Description |
|---------|-------------|
| **Aim** | Purpose of the experiment |
| **Objective** | Learning objectives |
| **Algorithm** | Step-by-step algorithm |
| **Flowchart** | Diagram of the process flow |
| **Code** | Source code or link to code file |
| **Output** | Sample output / screenshots |
| **Result** | Observed result after execution |
| **Conclusion** | Summary of learning |

## 🗂️ How to Navigate This Repository

1. **Browse by Unit** — Go to `Unit-1` through `Unit-5` for unit-specific assessments.
2. **Lab Work** — Open `Experiment/Experiment-N/README.md` for any experiment's documentation.
3. **Project Files** — Find all capstone materials under `Capstone-Project/`.
4. **Assignments** — Find assignment submissions under `Assignments/`.
5. **Certificates** — All certificates are stored in `Certificates/`.
